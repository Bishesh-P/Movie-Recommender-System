# 🎬 Movie Recommender System

A content-based movie recommender built with the [TMDB 5000 Movie Dataset](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata), served through a [Streamlit](https://streamlit.io/) web app. Pick a movie you like, and the app suggests 5 similar titles along with their posters (fetched live from the TMDB API).

## How It Works

1. **Data preparation** (`Movie_Recommender_system.ipynb`)
   - Merges `tmdb_5000_movies.csv` and `tmdb_5000_credits.csv` on `title`.
   - Keeps only the useful columns: `id`, `title`, `overview`, `keywords`, `genres`, `cast`, `crew`.
   - Parses the stringified JSON columns (`genres`, `keywords`, `cast`, `crew`) into plain Python lists.
   - From `cast`, keeps only the top 3 billed actors.
   - From `crew`, keeps only the director(s).
   - Strips whitespace from multi-word names (e.g. `"Sam Worthington"` → `"SamWorthington"`) so they're treated as single tokens.
   - Combines `overview + genres + keywords + cast + crew` into a single `tags` column — a bag-of-words description of each movie.
2. **Vectorization & similarity**
   - Converts the `tags` text into vectors using `CountVectorizer` (top 5,000 features, English stop words removed).
   - Computes pairwise **cosine similarity** between all movie vectors.
3. **Recommendation**
   - For a selected movie, looks up its similarity row, sorts the other movies by similarity score, and returns the top 5 closest matches.
4. **Serialization**
   - The processed `movies` DataFrame and the `similarity` matrix are pickled to `movie_list.pkl` and `similarity.pkl` for fast loading in the app (avoids recomputing on every run).
5. **Web app** (`app.py`)
   - Loads the two pickle files (cached with `@st.cache_resource`).
   - Lets the user pick a movie from a dropdown.
   - On clicking **Recommend**, computes the top 5 similar titles and fetches each movie's poster from the [TMDB API](https://www.themoviedb.org/documentation/api) (cached with `@st.cache_data`).
   - Displays the 5 recommendations with posters in a 5-column layout.

## Prerequisites

- Python 3.9+
- A free [TMDB API key](https://www.themoviedb.org/settings/api)
- The `tmdb_5000_movies.csv` and `tmdb_5000_credits.csv` files (from Kaggle) if you want to regenerate the pickle files yourself

## Setup

1. **Clone the repo and install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

   Minimum required packages:

   ```
   streamlit
   pandas
   numpy
   scikit-learn
   requests
   ```

2. **Generate the pickle files** (skip this if `movie_list.pkl` and `similarity.pkl` are already provided)

   Run through `Movie_Recommender_system.ipynb` end to end. It will produce `movie_list.pkl` and `similarity.pkl` in the working directory — copy both into the same folder as `app.py`.

3. **Add your TMDB API key**

   Create `.streamlit/secrets.toml` in the project root:

   ```toml
   TMDB_API_KEY = "your_tmdb_api_key_here"
   ```

   >  Add `.streamlit/secrets.toml` to `.gitignore` — never commit your API key.

## Running Locally

```bash
streamlit run app.py
```

Then open the local URL Streamlit prints (usually `http://localhost:8501`).

## Deploying (Streamlit Community Cloud)

1. Push the repo to GitHub — **excluding** `secrets.toml`.
2. Create a new app on [share.streamlit.io](https://share.streamlit.io/) pointing at `app.py`.
3. In the app's **Settings → Secrets**, paste:
   ```toml
   TMDB_API_KEY = "your_tmdb_api_key_here"
   ```
4. Make sure `movie_list.pkl` and `similarity.pkl` are included in the repo (or generated at build time), since the app loads them directly from disk.

## Notes & Limitations

- This is a **content-based** recommender (based on plot overview, genres, keywords, cast, and director) — it doesn't use user ratings or collaborative filtering, so recommendations reflect textual/metadata similarity rather than "people who liked this also liked."
- The similarity matrix is a dense `N × N` array; it works fine for ~5,000 movies but won't scale to very large catalogs without a different approach (e.g. approximate nearest neighbors).
- Poster fetching depends on TMDB API availability; if a request fails or times out, a placeholder image is shown instead.
